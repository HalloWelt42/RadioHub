# Откуда станции

Список станций взят из открытого каталога [radio-browser.info](https://www.radio-browser.info) (интерфейс api.radio-browser.info). Звук передают сами станции. Владельцы, которые не хотят быть в списке, могут сообщить об этом через [проект на GitHub](https://github.com/HalloWelt42/RadioHub).
