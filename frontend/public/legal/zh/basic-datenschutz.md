# 隐私

适用于 hallowelt42.github.io/RadioHub 上的 RadioHub Basic。RadioHub Basic 完全在您的浏览器中运行: 无账户、无 Cookie、无广告、不分析您的行为。

## 负责人

HalloWelt42

## 打开页面

页面托管在 GitHub Pages (GitHub, 美国)。打开时, GitHub 出于安全目的会记录您的 IP 地址。详情见 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。法律依据是安全提供页面的合法利益 (GDPR 第 6 条第 1 款 f 项)。

## 收听电台

电台列表是页面的一部分。搜索和筛选时不会传输任何内容。播放电台时, 您的浏览器会直接与其连接。电台会看到您的 IP 地址、浏览器信息以及请求来自本页面。许多电台还使用其他服务, 包括欧盟以外的服务。适用各电台的隐私政策。

## 电台标志

列表中的标志由浏览器直接从各电台的服务器加载, 在显示列表时就会加载。传输的信息相同。

## 播客

搜索播客时, 您的搜索词和 IP 地址会发送到 Apple (iTunes Search) 和 fyyd 的目录。节目列表、图片和声音由浏览器直接从您打开或订阅的播客服务器加载。

## 浏览器中保存的内容

外观、语言、音量、收藏、规则、搜索记录、上次收听的电台、带收听位置的播客订阅、闹钟, 以及您填写的用于日出日落的地点。这些信息保留在浏览器的存储中, 不会传给我们。它们是所需功能必需的 (德国 TDDDG 第 25 条第 2 款第 2 项)。您可以在浏览器的网站数据中删除。

只有当您按下相应按钮并在浏览器中允许时, 页面才会获取位置。
